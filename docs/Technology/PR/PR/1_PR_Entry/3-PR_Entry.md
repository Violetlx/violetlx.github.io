### 选择您的平台

Premiere Pro 和 After Effects 在 Windows 和 Apple 计算机上能同样良好地运行。由于视频和动态图形工作流程中存在许多变化，因此不同的设置之间总会存在差异。但是，借助健全的系统、对视频格式的基本理解和编辑工作流程，可以对其进行成功管理。

> **注意:**
>
> Premiere Pro 和 After Effects 提供对 Apple Silicon 系统的原生支持。

**MacOS 的优点**

集成良好的硬件和软件，以及可供选择的现成配置。通常情况下，对于视频，系统需要配备至少 16 GB 内存、SSD 存储、具有 AMD 显卡的 Apple Silicon 系统处理器或高速 Intel 处理器。

**Windows 的优点**

选择多样且可升级，还能经常实现成本节省。您可以根据自己的需求和预算配置系统，或者选择 Dell、Lenovo、HP 和专业视频工作站公司（例如 Puget Systems）的经测试适合运行 Premiere Pro 的配置。

Windows 可以更轻松地进行升级，这意味着系统的生命周期更长。



### 笔记本电脑还是台式机？

视频编辑工作的需求比较苛刻，需要强大的处理能力和快速的存储。您可以在桌面和移动系统中配置这些要求。台式机通常会有更高的性价比，包括更多配置选项，并且通常更易于升级。

笔记本电脑在便携性方面的优点明显，而且可以连接到外部显示器，还可以通过外部存储和 eGPU 进行增强。同等性能的情况下，笔记本电脑可能会更加昂贵。

**Apple 台式机**

至少配备 16GB 内存和 SSD 存储的当前 Mac Pro、iMac Pro、M1 iMac 和 Mac Mini 型号可满足视频编辑工作流程的需求。

**Apple 笔记本电脑**

至少配备 16GB 内存和 SSD 存储的 MacBook Pro 笔记本电脑型号可满足标准视频编辑工作的需求，包括高清和 4K 媒体。

**Windows 台式机**

装配或选购具有高速多核 CPU、AMD 或 NVIDIA 显卡、高速 SSD 存储以及 32GB 或更多内存的配置。

**Windows 笔记本电脑**

不同型号的 Windows 笔记本电脑提供了许多选项，可用于配置满足您需求的视频编辑工作站。

> **注意:**
>
> 您也可以从 Dell、Lenovo、HP 和专业视频工作站公司（例如 Puget Systems）提供的经测试适合运行 Premiere Pro 的台式机配置中选择。

### 需要多少存储空间？

视频文件很大，因此您需要大量空间。除了高速板载存储之外，建议您至少使用一个高速外部存储设备来支持编辑工作流程（SSD 或带 Thunderbolt 接口或 USB 3.1 接口的 NVMe 硬盘）。我们建议使用额外的大容量存储设备来对完成的视频项目进行归档。



### 文件大小和位深度

#### 文件大小

目前，两个最常见的视频内容分辨率是高清和 4K。高清素材的屏幕像素（宽度 x 高度）测量值通常为 1920 x 1080，而 4K 素材是其四倍，即 3840 x 2160。

| 高清                                                         | 4K                                                           |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 高清文件较小，这意味着它们占用的硬盘空间较少，更易于编辑，并且在导出时速度更快。YouTube 上的大多数内容仍是高清分辨率。 | 4K 文件占用更多的存储空间，并需要更多的计算能力来播放和导出。4K 的优点是图像的细节更丰富，并且在裁剪时有更大的操作空间，不会影响到品质。 |

### 配置系统

构建视频工作站的四个关键因素是处理器 (CPU)、内存、显卡 (GPU) 和存储。配置良好的高端系统可以很好地运行 Premiere Pro 和 After Effects。了解每个应用程序使用系统资源的方式将有助于您根据需要构建最佳系统。



#### **处理器**

After Effects 和 Premiere Pro 得益于 3.2 GHz 或更高的 CPU 时钟速度。

随着过渡到多帧渲染，After Effects 可以利用多核 CPU。从 After Effects 22.0 开始，用户应该能立即体验到预览和导出的性能改进。在高性能系统中，After Effects 多帧渲染的速度快 4 倍。我们强烈推荐 Core i7 或 Core i9 Intel 处理器或同等 AMD 产品。

**Premiere Pro：**对于 Premiere Pro，8 核就足以满足要求。Premiere Pro 在 8 核处理器上运行的效率是 93-98%，具体情况取决于任务。

- 至少 Core i7 或 Core i9 Intel 处理器、同等 AMD 产品或 Apple Silicon 系统处理器。Intel Core i7 和 Core i9（以及最新的移动端 Xeon 处理器）采用 QuickSync 技术，可加快 H.264 和 HEVC 的解码或回放速度。
- 部分桌面版 Intel Xeon 处理器不提供 QuickSync。这些可能更适合用于涉及电影摄像机格式（例如 RED、Sony Venice、ARRI）和广播格式（例如 XDCam HD）的高端工作流程。

**After Effects：** 对于 After Effects 22.0 及更高版本，8 核或 12 核 CPU 是一个很好的起点。对于高要求的工作流程，32 核能充分利用多帧渲染。

内存量也会影响 After Effects 使用可用 CPU 内核的方式。

- AMD Ryzen 7（8 核）或 Ryzen 9（12 或 16 核）提供出色的性能，且支持 64GB 和更高容量的内存。
- 对于非常高性能的 AMD Threadripper（24 或 32 核）或 Intel Xeon（24 或 32 核），支持 256GB 和更大内存
- 对于同时运行 Premiere Pro 的 After Effects 用户，请考虑对 H.264 和 HEVC 格式采用具备 QuickSync 硬件加速的 Intel Core i7 或 Core i9。使用至少 32 GB 内存。



#### **内存**

**Premiere Pro：**Windows 系统或基于 Intel 的 Mac 视频编辑工作站应具有 32 GB 或更多内存。对于 Apple Silicon 系统，建议使用 16 GB 的共享内存（当前最大可用）。

**After Effect 22.0 或更高版本：**建议至少配备 64 GB 内存。作为多帧渲染的经验法则，为每个 CPU 核心提供 4 GB 内存，加 20 GB，然后向上舍入到最接近的标准内存配置。



#### **显卡**

Premiere Pro 和 After Effects 的设计充分利用了 GPU。

**Premiere Pro：**建议使用至少配备 4 GB 显存 (VRAM) 的 GPU。多个 GPU（包括 eGPU）将提高 Premiere Pro 中的导出和渲染速度。

**After Effect 22.0 或更高版本：**建议使用配备至少 8 GB 显存的 GPU。

AppleSilicon 系统使用共享内存进行图形处理。我们建议使用具备至少 16GB 统一内存的 Apple Silicon 系统进行视频编辑。

**确保图形驱动程序是最新的！**

过时的图形驱动程序，是导致视频应用程序性能问题的最常见原因之一。为了获得优异性能，请确保安装了适用于 GPU（包括集成 Intel GPU）的最新驱动程序。有关更多信息，请参阅 [Premiere Pro 的 GPU 和 GPU 驱动程序要求](https://helpx.adobe.com/cn/premiere-pro/kb/gpu-and-gpu-driver-requirements-for-premiere-pro.html)。



#### **存储**

快速存储对于视频制作至关重要，这就需要使用快速 SSD 或 NVMe 存储。如果没有快速 RAID 阵列，旋转型磁盘无法为高清和超高清视频提供足够的速度。

- SSD 或 NVMe 闪存驱动器
- 对于本地存储，最佳设置是使用三个驱动器：
  - *系统驱动器*，用于操作系统和应用程序
  - *媒体缓存*驱动器 - 加速器文件，包括峰值文件 (.pek) 和匹配的音频 (.cfa)。Premiere 每秒可对这些文件进行数千次调用。
  - *媒体驱动器*，用于视频资源以及其他项目媒体

您可以使用高速外部驱动器来存储媒体和媒体缓存。如果只有两个驱动器，则可以将媒体缓存和媒体存储在同一驱动器上。

**共享存储：**通过 10Gps 或更高速的快速连接，Premiere Pro 和 After Effects 可以很好地与网络附加存储 (NAS) 系统配合使用，包括使用 macOS 和 Windows 的混合型环境。对于共享存储，应始终为单个用户在本地存储媒体缓存。

### 升级您的系统

如果要升级系统以提高 Premiere Pro 和 After Effects 的性能，则增加内存既是最简便、通常也是最有效的做法。

**按照以下优先级顺序升级 Premiere Pro 系统：**

1. 添加更多的内存 - 如果主板支持，最高可达 128 GB（尤其适合长篇幅的内容）
2. 更快的 GPU 或额外的 GPU 可使 Premiere Pro 实现更快的导出和渲染
3. 存储空间：更快（或额外）的 SSD 或 NVMe 驱动器
4. 具有较快时钟频率的 CPU

**针对 After Effect 22.0 或更高版本，按以下优先级顺序升级您的系统：**

1. 32 核 CPU 可以充分发挥[多帧渲染的优势](https://helpx.adobe.com/cn/after-effects/using/multi-frame-rendering.html)。
2. 添加更多内存 - 128 GB 或更多，具体取决于用例。
3. 为共享存储添加更快的 SSD 或 NVMe 的驱动器或是更快的连接。
4. 具有超过 8 GB 显存的更快的 GPU。



### 常见问题解答

#### 如何提高导出速度？

图形硬件和工作流程都会影响导出时间。辅助 GPU（与主 GPU 同类的 GPU）可以显著提高导出速度。[在编辑过程中创建预览](https://helpx.adobe.com/cn/premiere-pro/using/bestpractices-export.html)也可以缩短导出时间。

#### 如何针对多机位工作流程优化 Premiere Pro？

假设您的系统性能优良，则多机位工作流程的性能更多地取决于项目设置，而不是硬件。专业用户会[创建自己的项目模板](https://helpx.adobe.com/cn/premiere-pro/using/bestpractices-projects.html)来实现设置标准化。

#### 需要外部参考监视器吗？

强烈建议通过外部传输硬件来连接经过校准的参考监视器，以准确显示交错内容和色彩关键内容。若要妥善监视 HDR 内容，需要支持 HDR 功能的外部显示器。

#### 视频编辑的最佳显示设置是什么？

这是涉及个人偏好的问题。由于时间轴是 Premiere Pro UI 的核心元素，37 英寸超宽显示屏与辅助参考显示器相结合，将是一个出色的方案。

#### 如果我想使用多声道音频，您有什么好建议？

若要同步监视多声道音频，需要多声道声卡。在 Windows 上，声卡应当支持 ASIO 功能。

#### 工作流程对性能有多大影响？

工作流程和使用的文件格式，会对整体性能产生显著影响。我们的[使用原生格式的最佳做法指南](https://helpx.adobe.com/cn/premiere-pro/using/best-practices-formats.html)，提供了关于设计工作流程的建议，以确保您的硬件实现最佳性能。

## Premiere Pro 的 GPU 和 GPU 驱动程序要求

在 Adobe Premiere Pro 中，计算机的图形处理单元 (GPU) 在加快各种视频编辑任务方面起着至关重要的作用，可以显著提高性能。 

以下是其主要功能的细分介绍：

- **硬件加速解码：**加快常用格式的回放。
- **渲染时间轴以进行回放和导出：**这包括效果和常规合成。
- **硬件加速编码：**这可加快导出到某些常用格式的速度。
- **人工智能和机器学习处理：**包括场景编辑检测、转录和字幕生成在内的 Sensei 机器学习功能，在 GPU 或专用机器学习硬件上运行。

为确保良好的性能和可靠性，必须在操作系统中安装最新的 GPU 驱动程序。有时，升级到 Premiere Pro 的新版本可能需要安装更新的视频驱动程序。此外，如果 Adobe 知道某个特定驱动程序版本可能与我们的应用程序不兼容，在应用程序启动时将显示系统兼容性报告。 

遵循以下步骤，确保您的视频驱动程序已更新。如果 IT 部门负责管理您的计算机，请在安装新的驱动程序之前与其沟通，因为部分组织会集中管理驱动程序安装。 



### 在 Windows 上更新视频驱动程序

可以使用 Windows 更新来更新 AMD、Intel 和 NVIDIA GPU 的视频驱动程序。有关使用 Windows 更新的信息，请参阅 [Microsoft 文档](https://support.microsoft.com/zh-cn/windows/install-windows-updates-3c5ae7fc-9fb6-9af1-1984-b5e0412c556a)。



### 在 macOS 上更新视频驱动程序

Macintosh 计算机的视频驱动程序作为 macOS 系统更新的一部分进行更新。要更新 macOS 版本，请参阅 [Apple 文档](https://support.apple.com/en-us/108382)。





## GPU 加速渲染和硬件编码/解码

本文对 Adobe Premiere Pro 和 Adobe Media Encoder 中的 Mercury Playback Engine（GPU 加速）和硬件解码/编码进行了详细的介绍。



### Mercury Playback Engine（GPU 加速）渲染器

Adobe Premiere Pro 和 Adobe Media Encoder 可以利用系统上可用的 GPU 来的在 CPU 和 GPU 之间分配处理负载，以获得更好的性能。当前，大部分的处理均由 CPU 完成，GPU 仅协助处理特定的任务和功能。

#### GPU 加速渲染器可以处理哪些内容？

Mercury Playback Engine（GPU 加速）渲染器可用于渲染 GPU 加速效果和功能。

#### Adobe Premiere Pro 是否使用多 GPU 设置 (SLI/ CrossFire) 来处理 GPU 加速效果和功能？

Adobe Premiere Pro 在播放过程中使用单个 GPU，而对于其他任务（如**渲染入点到出点**和导出），则使用多个 GPU。可以将 CrossFire 设置为将多个 GPU 显示为单个逻辑 GPU，在这种情况下，Adobe Premiere Pro 会将其视为单个 GPU。

如果使用多 GPU（非 SLI 或非 CrossFire）配置，建议禁用系统或基于驱动程序的自动 GPU/图形切换功能。



#### 为何我会看到集成 Intel® GPU 而不是专用 GPU 上的活动？

运行在专用 GPU 上的 Mercury Playback Engine 并不用于处理与 GPU 相关的任何内容。集成 GPU 可用于特定的任务，例如编码/解码特定编解码器和用户界面 (UI) 活动，这些活动可能会在监视 GPU 使用情况时显示。



#### 为何我的 GPU 使用率很低？

GPU 的使用率取决于几个因素。在编辑和渲染时，GPU 的使用率可能会或可能不会达到最大值，具体取决于所使用的 GPU 加速效果/功能的数量和 GPU 的计算能力。因此，像 NVIDIA RTX 2080 这样功能强大的 GPU，其执行速度可能比 NVIDIA GTX 1060 更快，但它的使用率可能更低，因为这种 GPU 功能强大，而且与 NVIDIA GTX 1060 或其他中端 GPU 相比，在处理相同的信息时，它所需要的硬件资源更少。如果使用的 GPU 加速效果较少，那么 GPU 使用率可能不会很高，而当所使用的 GPU 加速效果增多时，其使用率可能会增加。



#### 为何我会看到“此效果需要 GPU 加速才能正常工作”？

这种情况只适用于 VR 效果。当 GPU 没有足够容量的 VRAM 来处理效果时，就会显示此消息。



### 硬件加速解码和编码 

Premiere Pro 支持硬件加速编码，以加速编码（导出）性能，缩短导出 H.264和 H.265 (HEVC) 格式的用时。 Premiere Pro 也支持 H.264 和 H.265 格式的硬件加速解码，以优化时间轴播放性能。

要使用这些功能，必须安装具备硬件加速编码和解码能力的 GPU。
从此信息中检查您的 GPU 是否支持硬件加速解码和编码。

- **[NVIDIA](https://developer.nvidia.com/video-encode-and-decode-gpu-support-matrix-new)**
- **[Intel](https://www.intel.com/content/www/us/en/docs/onevpl/developer-reference-media-intel-hardware/1-0/overview.html)**
- **[AMD](https://www.amd.com/en/products/specifications/graphics)**
- **Apple Silicon**

Apple Silicon（M1 及更高版本）支持 H.264 和 H.265 格式的硬件加速解码和编码，包括 10 位 4:2:2 解码支持。 HEVC HLG 4:2:0 10 位编码仍然采用软件编码方式。 

以下是硬件加速解码和编码的[系统要求](https://helpx.adobe.com/cn/premiere-pro/system-requirements.html#hardware-acceleration-system-requirements)。



### 支持硬件加速编码 

从**导出设置**下的**格式**下拉菜单中选择 **H.264/HEVC**，以激活此选项。 然后在**视频**选项卡下，转到**编码设置**并将**性能**设置为**硬件加速**。

![启用硬件编码](https://helpx-prod.scene7.com/is/image/HelpxProdLoc/GPU-encoding-27?$png$&jpegSize=300&wid=1710)

#### 支持的编解码器平台

**编码：**H.264/AVC（8 位）、HEVC 4:2:0（8 位和 10 位），最高 4096x4096。 借助第 10 代及更高版本的 Intel® 酷睿™处理器，HEVC 编解码器支持的分辨率可高达 8192x8192。

**针对 HEVC 4:2:0 10 位硬件加速编码建议的 Intel 驱动程序和处理器版本**

第 9 代、第 10 代、第 11 代和第 12 代 Intel® 酷睿™ 处理器支持 HEVC 4:2:0 10 位编码。 有关更多信息，请参阅 [Intel 文档](https://www.intel.com/content/www/us/en/develop/documentation/media-capabilities-of-intel-hardware/top.html)。



### 支持硬件加速解码

与硬件加速编码一样，Adobe Premiere Pro 也支持使用硬件加速解码，以在时间轴中配合使用 H.264/AVC、HEVC 媒体时提供更好的播放性能。

启用硬件加速解码的步骤：

1. 导航至**首选项** > **媒体**。
2. 选中**启用硬件加速解码（需要重新启动）**。
3. 重新启动 Adobe Premiere Pro。

#### 支持的编解码器平台

该功能适用于 MP4 媒体，尤其是 H.264/AVC 和 HEVC 编解码器。Premiere Pro、Adobe Media Encoder 和 After Effects 版本 22.0 及更高版本在 Intel 平台上支持 HEVC 4:2:2 10 位硬件加速解码。

不支持 M2TS（MPEG-2 传输流）。如果使用 4K M2TS 媒体，则将其转码为受支持的 MP4 编解码器可能有助于获得更好的播放性能，因为转码后的 MP4 媒体可以使用硬件加速解码（如果转码为 HD M2TS 媒体，则性能增益可能不是很大）。

在具有 8 GB 或更少 RAM 的系统上，集成 Intel® GPU 上的硬件加速解码处理可能会受到限制，并且可能导致 CPU 接管处理，因为集成 GPU 使用 RAM 作为共享 GPU 存储器。建议使用 16 GB 或更大容量的 RAM，以获得更好的性能。

### 硬件加速解码、Mercury Playbck Engine（GPU 加速）和硬件加速编码之间的区别

- Mercury Playbck Engine（GPU 加速）是一个用于处理 GPU 加速效果并增强播放的渲染器。
- 在 H.264/AVC 和 HEVC 编解码器中导出时间轴时，使用硬件加速编码可加速解码性能。
- 硬件加速解码是一种用于在播放时间轴时加速解码 H.264/AVC 和 HEVC 媒体的流程。
